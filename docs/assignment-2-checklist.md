## Meaningful Commit Practice

Commit real completed changes with descriptive messages. For example, a single reviewed migration commit can be named "Migrate research collection to smart-farming digital twins". Separate commits are appropriate only for genuinely separate reviewed work. Do not fabricate timestamps or claim five new development stages that did not occur.
